# 硬币判官 · 设计规范（初版 v0.9）

> **这份文档是什么**：项目的全部视觉规则汇总，独立于需求文档存在。
> 以后做任何页面、任何新项目，照这份文档取色/取字号/取圆角，风格就永远统一。
> **状态**：初版（返工阶段产出），P3 收尾时定稿为 v1.0。与代码冲突时，以 `src/index.css` 的 CSS 变量为准。

## 1. 色板

### 1.1 品牌色

| 色值 | 用途 | CSS 变量 |
|------|------|----------|
| `#5BB8FF` | **主题蓝**：选中态、主按钮、卡片渐变起点 | `--color-primary` |
| `#3A9FE8` | 深一号蓝：卡片渐变终点 | `--color-primary-dark` |
| `#F0F8FF` | 浅蓝底：选中标签、会员小药丸底色 | `--color-primary-bg` |

铁律：**全站只允许这一套主题色**，旧版橙色 `#FF6B35` 永久弃用。

### 1.2 功能色（语义色，全站含义固定）

| 色值 | 含义 | 变量 | 浅底版（小标签用） |
|------|------|------|------|
| `#2ECC71` | 值得 / 正向 | `--color-success` | `#EAF9F1` → `--color-success-bg` |
| `#F39C12` | 待回顾 / 提醒 | `--color-warning` | `#FEF4E4` → `--color-warning-bg` |
| `#E74C3C` | 不值得 / 危险操作 | `--color-danger` | `#FDEDEB` → `--color-danger-bg` |

语义绑定：值得=绿、不值得=红、会员=浅蓝，**任何页面不得换含义**。

### 1.3 中性色（双主题）

| 用途 | 浅色 | 深色 | 变量 |
|------|------|------|------|
| 页面背景 | `#F8F7F4` 米白 | `#12141A` | `--color-bg` |
| 卡片背景 | `#FFFFFF` | `#1C1F27` | `--color-card` |
| 边框/分割线 | `#F0EEE8` | `#272B35` | `--color-border` |
| 主文字 | `#1F2430` | `#F2F4F8` | `--color-text-1` |
| 次文字 | `#6B7280` | `#9BA1AD` | `--color-text-2` |
| 弱文字/占位 | `#A0A4B8` | `#5C6270` | `--color-text-3` |

### 1.4 专用色

| 用途 | 值 | 说明 |
|------|-----|------|
| 数字键盘 | 底 `#1A1A2E` / 键 `#2D2D44` / 键高亮 `#3D3D5C` | 双主题下都保持深色（品牌特征） |
| 原则提示条 | 底 `#FFFBF0` / 边 `#FFE082`（深色 `#2E2A18`/`#57491F`） | 记账弹窗内 |
| 蓝色卡面上的白 | 坐标轴 30% 白 / 柱条 70% 白 / 小字 60% 白 / 轨道 15% 白 | 见 `--color-oncard-*` |

**使用规则**：代码里只许写 `var(--xxx)` 或 Tailwind 映射类（如 `bg-primary`、`text-text-2`），**禁止硬编码十六进制色值**。

## 2. 字号阶梯

| 档位 | 大小 | 用在哪 |
|------|------|--------|
| 大数字 | 26px light | 卡面金额（¥总资产、本月余额） |
| 页面大标 | 22px | 页面标题、空卡"未开卡" |
| 标题 | 17–18px semibold | 页头标题、区块标题 |
| 正文 | 14px (`text-sm`) | 列表主文字、按钮 |
| 辅助 | 12px (`text-xs`) | 列表次行、说明文字 |
| 卡面小字 | 11px | 卡面标签（"总资产"等） |
| 提示 | 10px | 卡面角落引导（"管理账户 →"） |
| 微字 | 9px | 刻度、角标 |

数字一律 `tabular-nums`（等宽数字，跳动时不抖）。
字体栈：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Helvetica Neue', 'Microsoft YaHei', sans-serif`。

## 3. 圆角与阴影

### 3.1 圆角阶梯

| 档位 | 值 | 用在哪 |
|------|-----|--------|
| s | 8px | 小标签、四宫格小块 |
| m | 12px | 输入框、小卡片 |
| l | 16px | 普通卡片 |
| xl | 24px | 大容器、弹窗顶角 |
| 全圆 | 999px | TabBar 胶囊、小药丸 |

**例外：银行卡不用固定圆角**，见第 4 节。

### 3.2 阴影三级

| 档位 | 值 | 用在哪 |
|------|-----|--------|
| 卡片 | `0 2px 12px rgba(0,0,0,.06)` | 普通白卡 |
| 导航 | `0 4px 24px rgba(0,0,0,.12)` | TabBar |
| 浮层 | `0 8px 32px rgba(0,0,0,.15)` | 弹窗 |
| 蓝卡 | `0 8px 24px rgba(91,184,255,.3)` | 银行卡（彩色投影，制造"浮起的发光卡"感） |

深色主题下阴影加深（.35/.45/.5），蓝卡投影不变。

## 4. 银行卡组件规范（核心视觉，v2.1 重制）

| 规则 | 值 | 原因 |
|------|-----|------|
| 宽高比 | `aspect-ratio: 85.6 / 54` | 真实银行卡比例 |
| 圆角 | `border-radius: 4% / 6%`（百分比） | 真卡圆角≈卡宽 3.7%/卡高 5.9%；用百分比则任何尺寸观感一致 |
| 宽度 | 内容宽 − 32px（左右各留 16px） | 手机上约 370–398px |
| 桌面端 | **绝不放大**，保持手机物理尺寸 | 卡片被拉宽是 v2.0 最大败笔 |
| 背景 | 135° 蓝渐变 `#5BB8FF → #3A9FE8` | 未开卡状态用灰渐变 |
| 投影 | 蓝色彩色投影（见 3.2） | |

代码实现：CSS 类 `.bank-card` + 组件 `src/components/BankCard.tsx`（active 控制蓝/灰）。

## 5. 小怪兽角色规范（品牌 IP，必须保留）

### 5.1 角色造型（来自 `public/icon.svg`）

- **画法**：纯像素风，`<rect>` 方块拼成，`shape-rendering="crispEdges"`（边缘不许抗锯齿）。
- **网格**：200×200 画布，8px 为基本单位。
- **身体**：白色矩形（96×72），顶部 8px 高光 `#F0F4FF`，右侧和底部阴影条 `#DDE4F0`。
- **眼睛**：两个 20×20 黑色方块，间距 20px。
- **四肢**：12×12 白色手臂×2；28×16 白色腿×2（带 6px 阴影条）。
- **配角：像素金币**：外圈 `#F9A825`、内芯 `#FFD54F`、高光 `#FFF9C4`、`¥` 符号 `#F57F17`。
- **场景底**：蓝渐变 `#5BA8F5 → #6DB4F7`。

### 5.2 使用场景

1. App 图标（现有，不动）。
2. **空状态插画**（P2 补齐）：同一角色的不同动作/表情——暂无记录（摊手）、暂无原则（举牌）、待回顾为空（满意）等；手绘 SVG 直出，保持像素风和配色。
3. 远期：AI 化形象（需求文档第 12 节）。

### 5.3 禁止事项

- 不许改成圆角/渐变身体的"现代风"怪兽；像素方块是它的身份证。
- 不许换身体颜色（白身黑眼是定死的）。

## 6. 组件清单

| 组件 | 关键样式 |
|------|----------|
| TabBar | 底部悬浮胶囊：全圆角、毛玻璃 `rgba(255,255,255,.88)`（深色 `rgba(28,31,39,.88)`）+ 导航阴影；中央 + 号圆形蓝钮上浮 8px；适配 safe-area |
| PageHeader | 固定顶栏：白底（`--color-card`）+ 底边框，图标 + 17px 标题，宽 430 居中 |
| BankCard | 见第 4 节 |
| RecordModal | 底部弹窗：圆角 xl 顶角、上滑入场 0.35s；金额大字 → 分类 → 情绪 → 审判 → 日期 |
| Numpad | 深色键盘（双主题都深色）：键 `#2D2D44`，按下 `#3D3D5C` |

| 小药丸标签 | 功能色浅底 + 功能色文字，圆角全圆，10–11px |
| EmptyState | 居中：小怪兽插画（P2 起）+ 14px 弱文字标题 + 12px 描述 |
| 进度条 | 轨道 15% 白（卡面上）/ border 色（白卡上），填充 0.4–0.5s 过渡 |

## 7. 图标规范

- 全部**内联手写 SVG**，禁止图标库（`src/components/icons.tsx`）。
- 风格：24×24 viewBox、描边 `stroke="currentColor"`、线宽 1.6–1.8、圆角线帽线 join——手绘线条风。
- 卡面图标 stroke 用白色。
- 分类用 emoji（🍜🛍🎮🚇🏠📦），不画 SVG。

---

## 8. 布局规范

| 规则 | 值 |
|------|-----|
| 内容列 | 永远最大宽 430px 居中（`.shell`），手机铺满 |
| 桌面端 | 内容列不变；两侧留白 + 极淡蓝装饰（radial 渐变 ≤5% 透明度）；内容列细描边 + 轻投影 |
| 固定元素 | 页头/TabBar/弹窗/底栏永远 430 居中（`.shell-fixed` / `.modal-fixed`） |
| 页面侧 padding | 16px |
| 底部留白 | 页面 `pb-28`，避开悬浮 TabBar |

## 9. 动效参数表

| 动效 | 位置 | 参数 |
|------|------|------|
| 页面切换淡入 | 全站 | 0.12s ease（`.page-fade`） |
| 记账成功数字弹跳 | 金库大数字 | 0.4s `cubic-bezier(0.34,1.56,0.64,1)`（`.success-bounce`） |
| 列表逐条上浮 | 流水前 10 条 | 0.3s + 50ms/条（`.item-enter`） |
| 弹窗上滑 | 底部弹窗 | 0.35s `cubic-bezier(0.32,0.72,0,1)`（`.sheet-slide-up`） |
| 遮罩淡入 | 弹窗背景 | 0.25s（`.overlay-fade`） |
| 按压缩放 | 全站可点 | `:active` scale 0.92–0.98（`.pressable` 0.95；TabBar + 号 0.92） |
| 进度条过渡 | 卡面/统计 | 0.4–0.5s width |

原则：**动效只做"反馈"，不做装饰**；没有新动效需求时不新增。
